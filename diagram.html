Hybrid Key Demo Map

How the Flask web component for "Enhancing Secure File Transfer Resilience Against Advanced Decryption Threats Using Hybrid Key Encapsulation" is put together, and what happens when a request arrives.

One request, step by step

Following GET /hash?text=hello:

  1. The browser sends the request to the Flask server on port 5000.
  2. Flask matches the URL to hash_route() in app.py.
  3. The handler reads text and calls sha256_hash("hello") from crypto_service.py.
  4. The function returns 2cf24dba…938b9824.
  5. The handler wraps it with jsonify and the browser prints the JSON.
